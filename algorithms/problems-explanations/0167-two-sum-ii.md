## О чем задача

Суть: дан отсортированный массив чисел и цель `target`, нужно вернуть пару индексов. Сумма элементов по этим индексам равна цели. Индексы возвращаются с 1, а не с 0.

В условии сказано, что всегда существует ровно одно решение. Также сказано, что нельзя использовать один элемент два раза.

## Первая мысль

Тут на самом деле все просто, и решение находится сразу по теме «два указателя». Она буквально задача из примера.

Нужно пользоваться тем, что массив отсортирован, следовательно, числа идут по порядку. Дальше нужно понять, как находить сумму. Если брать сумму крайних элементов, нетрудно заметить: если взять второй элемент вместо первого, то сумма вырастет, а если взять предпоследний элемент вместо последнего, то сумма уменьшится.

Это и есть ключевая идея задачи. Мы точно знаем, что решение есть, значит, берем сумму крайних элементов за старт и идем к центру массива, пока не найдем нужную сумму. Возвращаем индексы элементов, которые в сумме дали ответ.

Наивный вариант — перебрать все пары двумя вложенными циклами, это `O(n^2)`. Он не использует сортировку вообще.

## Ключевая идея

Тут прикол в свойстве отсортированного массива и метода двух указателей с краев. Если сумма меньше цели, то левый элемент в паре с **любым** другим правым даст еще меньше — значит, его можно выкинуть. Каждый шаг отсекает одного кандидата, и ответ не теряется. Это помогает найти сумму за `O(n)`, потому что мы просто проходимся по массиву чуть по-другому.

## Как решаю

1. Объявляю левый указатель на начало и правый на конец.
2. Прохожусь по массиву, пока левый меньше правого. Считаю сумму: если она меньше цели — сдвигаю **левый** вправо, если больше — сдвигаю **правый** влево.
3. Когда сумма найдена, возвращаю левый и правый указатели, прибавив к каждому 1.

## Код

```ts
function twoSum(numbers: number[], target: number): number[] {
    let l = 0;
    let r = numbers.length - 1;

    while (l < r) {
        const testSum = numbers[l]! + numbers[r]!;
        if (testSum < target) {
            l += 1;
        } else if (testSum > target) {
            r -= 1;
        } else {
            return [l + 1, r + 1];
        }
    }

    return [-1, -1];
}
```

## Сложность

- **Время:** `O(n)` — потому что мы проходимся по массиву в худшем случае по всем элементам один раз, тут нет ни вложенности, ни повторного поиска.
- **Память:** `O(1)` — потому что кроме переменных указателей и суммы мы ничего не объявляем, массив не копируем, матрицы не создаем.

## Крайние случаи

Пустой массив и случай без ответа по условию невозможны (длина ≥ 2, решение всегда есть). Стоит проверить:

- ответ лежит на самых краях массива: `[-1, 0], -1 → [1, 2]`
- одинаковые элементы: `[2, 2], 4 → [1, 2]`
- отрицательные числа: `[-3, -1, 0, 2, 5], 4 → [2, 5]`

## Как узнать такую задачу

Тут типичная задача на два указателя:

- дан **отсортированный** массив
- есть цель
- нужно найти **пару** элементов, которые дают цель
