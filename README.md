# Основные правила репозитория для меня

- Одна директория — один курс/учебник/проект.
- Внутри директории курса/учебника — разбивка по главам с нумерацией: **01-first-topic.md**.
- Глава пишется по памяти после её прохождения: что запомнил + что непонятно/забыл.
- Внутри директории курса — **cards.tsv** для Anki: `вопрос<TAB>ответ<TAB>тег`, тег = глава.
- Внутри директории проекта — свои директории проекта, как внутренний репозиторий.
- **NO AI SLOP** — все пишем ручками, от себя. Если что, сделаю репозиторий приватным.

# Курсы, которые я прошел

## Boot.dev. Git + Git 2.0

Основное в курсе — понимание Git. Он был разработан с ThePrimeagen, который в целом прикольный чувак, но еще и интересный рассказчик.
Этот курс и подтолкнул меня на создание этого репозитория и попытки запомнить все, что я изучаю. В курсе рассказывались не только базовые вещи по типу push, pull, но еще и plumbing-команды, чтобы смотреть в суть того, как работает система контроля версий.

Также в курсе было про фундаментальную систему того, как Git вообще хранит файлы и версии: есть 3 типа объектов — tree, blob и commit. Git хранит не дельту изменений, а всю версию целиком (снимок), сжимая объекты через zlib. Дельты появляются уже при упаковке объектов в packfile — для экономии места.
Новые интересные команды, конечно, использовать я их буду раза два в год, но набор инструментов, которые предоставляет Git, — mindblowing.
